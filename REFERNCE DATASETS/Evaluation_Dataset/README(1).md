# Evaluation Dataset

## Purpose

This dataset is used to evaluate MediGuard AI.

Each test case contains: - Medical Bill - Insurance Policy - Expected
Decision - Expected Denial Reason - Appeal Requirement - Expected Appeal
Template

## Folder Structure

-   Bills/
-   Policies/
-   Ground_Truth/
-   Test_Cases/

This dataset will be used to evaluate: - OCR accuracy - Insurance policy
verification - RAG retrieval accuracy - Appeal generation accuracy
