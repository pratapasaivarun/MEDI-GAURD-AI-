# Master Medical Bill Schema

## Description

This folder contains the master schema used in the MediGuard AI project.

The schema defines the standard structure for every synthetic medical bill that will be generated.

All OCR ground truth files, JSON annotations, and synthetic hospital bills will follow this schema.

## Files

- Medical_Bill_Schema.xlsx
- Medical_Bill_Schema.json

## Purpose

- Standardize medical bill generation
- Ensure consistency across datasets
- Support OCR annotation
- Support RAG knowledge base creation
- Support insurance claim verification
