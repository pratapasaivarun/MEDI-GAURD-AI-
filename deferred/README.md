# Deferred production features

These modules are retained for possible future work but are out of scope for the academic prototype.

- `paddle_ocr.py`: alternative PaddleOCR support; the active extraction pipeline uses Tesseract only.
- `policy_compare.py`: policy-edition comparison utility; the prototype uses one uploaded active policy per demonstration claim.
- `production_security.md`: implementation notes for MFA, encryption, HTTPS, monitoring, backups, secrets, and hardened authentication; none are required by the local academic demonstration.
